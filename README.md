# FURORE 2026 - Dayananda Sagar College of Engineering Cultural Fest

## About
FURORE is the annual cultural extravaganza of Dayananda Sagar College of Engineering, Bengaluru. This year's theme is "Whispers of Royalty" - transforming the campus into a grand medieval kingdom.

## Features
- **Responsive Design:** Works perfectly on mobile and desktop
- **Modern UI:** Royal medieval theme with gold accents
- **Event Management:** 37 events across 4 clusters
- **Professional:** DSCE branding and favicon
- **Optimized:** Fast loading with lazy loading images
- **Secure:** Production-ready Flask configuration

## Event Clusters
1. **Sovereign Stage** (35%) - Cultural performances
2. **Artisan's Guild** (20%) - Creative competitions  
3. **King's Council** (15%) - Literary events
4. **Warriors Arena** (30%) - Games and esports

## Tech Stack
- **Backend:** Flask (Python)
- **Frontend:** HTML5, CSS3, JavaScript
- **Styling:** Custom CSS with mobile responsiveness
- **Icons:** Unicode emoji for universal compatibility
